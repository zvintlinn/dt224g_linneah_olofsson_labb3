# CSS - Introducerande projekt

I detta projekt har vi fått implementera den kunskap vi fått om CSS. Vi fick en given wireframe som vi sedan gjore mockups till i Figma och därefter byggde webbplatsen utefter. Norrgläntan är en fiktiv destination och allt material så som bilder och texter var förbestämda för uppgiften.

## Min ambition

Det främsta jag ville uppnå med detta projekt var att skapa en webbplats med relevanta media queries för att kunna visas lika snyggt på både stor som liten skärm. Utöver detta så tänkte jag lite extra på färgsättning och jobbade fram en färgpalett utifrån de färger som fanns i de givna bilderna. Då de introducerande föreläsningarna även tog upp en del kring animering och transitions så var jag även inställd på att testa detta i praktiken.

## Projektets gång

När jag gjort mina mockups i Figma började jag utforma webbplatsens skelett i HTML. Jag var väldigt fast i tänket kring mobile first och glömde till en början att tänka på vilka divar jag skulle behöva för att lägga flex på stor skärm. Detta fick jag inse när jag väl började arbeta med mina media queries och är något jag kommer ta med mig till kommande byggen.
